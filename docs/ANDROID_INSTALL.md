# Zalma Phase 3 RC — установка

## Android APK

1. Откройте раздел [Releases](https://github.com/r1vlflow/Zalma/releases) репозитория и скачайте `Zalma.apk` из релиза `v2.6.0-rc.1`.
2. Открывайте APK только из официального GitHub-репозитория `r1vlflow/Zalma`.
3. Если Android блокирует установку, разрешите установку приложений именно для браузера/файлового менеджера, который открыл APK. После установки отключите это разрешение, если оно больше не требуется.
4. Откройте Almazov Schedule Hub. После первого сетевого открытия статика приложения сохранится для офлайн-запуска; сетевые функции требуют доступности соответствующего API.

После push в `main`/`master` с изменениями приложения APK собирается автоматически через **Build Android APK (RC)**. Его также можно запустить вручную через **GitHub → Actions → Build Android APK (RC) → Run workflow**. Workflow выполняет QA, устанавливает Android SDK, собирает `assembleDebug` и прикладывает файл `Zalma.apk` к GitHub Release. В этой версии это debug-signed APK для тестовой установки, не production-подпись Google Play.

## iPhone / iPad (PWA)

1. Откройте `https://r1vlflow.github.io/Zalma/` в Safari.
2. Нажмите **Поделиться** (квадрат со стрелкой вверх).
3. Выберите **На экран «Домой»** / **Add to Home Screen**. Если пункта не видно, прокрутите меню действий вниз и проверьте раздел редактирования действий.
4. Нажмите **Добавить**. Запускайте приложение с созданного значка.

## Установка PWA в Chrome на Android

Откройте сайт в Chrome и нажмите **Установить приложение** в настройках Zalma либо выберите соответствующий пункт меню браузера. Браузерный системный prompt появляется не во всех ситуациях; в этом случае используйте меню Chrome или APK.

## Проверка

- Сайт должен открываться по HTTPS.
- `manifest.webmanifest` обязан содержать 192×192 и 512×512 иконки, `start_url`, `scope` и `display: standalone`.
- После публикации проверьте `dist/version.json`, Service Worker и номер сборки в настройках приложения.
