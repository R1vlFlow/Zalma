# Almazov Universal Schedule Hub

Релизный PWA-сервис для просмотра расписания ИМО НМИЦ им. В.А. Алмазова.

## Архитектура
- строгий контекст `программа → курс → группа → событие`;
- Лечебное дело использует официальный JSON schema v7 при наличии сети;
- Педиатрия и Клиническая психология используют проверенный snapshot официальных PDF;
- неподтверждённые источники не превращаются в «достоверные» пары;
- лекции и ПЗ фильтруются независимо;
- дедупликация и валидация выполняются до рендера;
- на телефоне расписание становится вертикальным по дням, на большом экране — недельной сеткой;
- ДЗ хранятся локально с редактированием, удалением, импортом/экспортом;
- поддерживается экспорт текущей недели в ICS и печать.

## Источники
Главный источник расписания — кабинет студента ИМО. Публичная страница на 2026/27 учебный год содержит расписания по курсам и отдельные PDF для лекций/практики. На странице также есть отдельные ссылки на индивидуальные учебные планы.

## Запуск
Обычный static hosting / GitHub Pages. Service Worker требует HTTP(S), а не `file://`.

## Текущий релиз
- версия `1.1.1` / QA3;
- live-источник Лечебного дела: официальный JSON с атомарной синхронизацией;
- при недоступности сети используется последний валидный snapshot из IndexedDB;
- Педиатрия и Клиническая психология: официальный PDF snapshot для опубликованных курсов 1-2;
- расписание на телефоне и планшете в портретной ориентации переключается в вертикальный список по дням;
- для `1/2` и `2/2` сохраняется отдельная семантика;
- ДЗ остаются отдельным локальным модулем с импортом/экспортом;
- пустые/неоднозначные данные явно маркируются и не подменяются чужими занятиями.
